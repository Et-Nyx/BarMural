Correção da preparação do Android SDK no GitHub Actions para a prévia nativa.

- Runner fixado em Ubuntu 24.04.
- Command-line Tools 12.0 com checksum oficial verificado; pacotes SDK explícitos, sem o pacote legado `tools`.
- Ações checkout, Java, Gradle e upload atualizadas para v5.
- Mesma correção aplicada ao CI e aos dois workflows de Release.

Recursos e limitações do aplicativo permanecem os descritos na [prévia inicial](https://github.com/Et-Nyx/BarMural/blob/master/docs/releases/v0.1.0-native.md).
Acesso real ao Instagram e execução em dispositivo continuam sem validação nesta máquina.

O APK `barmural-0.1.1-native-preview.apk` usa uma chave de desenvolvimento gerada no workflow; pode ser necessário desinstalar uma prévia anterior para instalar, apagando dados locais. O APK de release sem assinatura também é fornecido. Não há chave de produção configurada.
